## 程序启动命令行参数
```
go run app.go --app=demo1 --port=8080 --profile=test --conf=/Users/liangboceo/go/

go run app.go --f ./conf/config_test.tml
```

## 环境变量
```
YUANBOOT_APP=demo1
YUANBOOT_PORT=8080
YUANBOOT_PROFILE=dev
YUANBOOT_CONF=/Users/liangboceo/go/
```

参数说明：
| 参数 | 说明 |
|-----|---|
| app | 应用程序名  |
| port| 服务启动端口 |
| f | 直接指定配置文件路径,下面两个参数将不生效  |
| profile| 配置环境，默认dev ( dev , test , prod )|
|conf| 配置文件目录 (默认与服务同目录匹配 {configname}_{profile}.yml) |
